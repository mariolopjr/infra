# infra

Nix flake for all my systems, built with [flake-parts](https://github.com/hercules-ci/flake-parts), [import-tree](https://github.com/vic/import-tree) and [den](https://github.com/denful/den). Every file under `modules/` is loaded automatically.

## Flake inputs

`flake.nix` is generated by [flake-file](https://github.com/denful/flake-file). Each input is declared in the module that uses it (`flake-file.inputs.<name>` next to the code), and the core inputs live in `modules/flake/flake-file.nix`.

After adding, changing, or removing an input, run `nix run .#write-flake` to regenerate `flake.nix`, then `nix flake lock`. `just rebuild` and `just update` run `write-flake` as well. `checks.<system>.check-flake-file` fails when `flake.nix` is out of date with the modules.

### winterfell gaming

For some games, the game renders on the iGPU. To fix that, use the following Steam launch options to force the game to render on the RTX 5080 through PRIME offload. Steam launch options:

```
nvidia-offload mangohud %command%
```

MangoHud opens on the full preset and shows only the 5080. `Shift_R+F12` toggles the HUD, `Shift_R+F10` cycles presets.

## Layout

- `modules/den.nix`: den setup and shared defaults, no hosts
- `modules/hosts/`: one file per machine, its `den.hosts` entry and aspect
- `modules/users/`: user config
- `modules/features/`: reusable aspects (desktop, neovim, git, etc)
- `modules/flake/`: this repo only: installer ISO and `infra-install`, e2e VM, checks, devshell, formatter, core flake-file inputs, and `flakeModules.default`
- `scripts/`: helper scripts called from the justfile

## Sharing with another flake

`flakeModules.default` is `den.nix`, `features/` and `users/`: no hosts and does not include things from `modules/flake/`. It does not reference `inputs.self` or a host name, and evaluates with the consumer's inputs, so pass this flake's inputs through:

```nix
{
  inputs.infra.url = "github:mariolopjr/infra";
  outputs = inputs:
    let all = inputs.infra.inputs // inputs; # upstream's pins; `nix flake update infra` bumps all
    in all.flake-parts.lib.mkFlake { inputs = all; } {
      imports = [ inputs.infra.flakeModules.default (all.import-tree ./modules) ];
    };
}
```

It also carries flake-file's option declarations (not its `write-flake` packages or `check-flake-file`), since shared modules declare their inputs with `flake-file.inputs`. The consumer gets those inputs through `infra.inputs`.

Aspect configuration merges only on hosts that include them, so a consumer that picks `workstation` and skips `desktop`, `gaming`, `disks`, `preservation` will only get what the `workstation` aspect defines. This configuration is included: `den.default` (nix settings, comma). Home config is per aspect, so a user picks its own, eg `den.aspects.alice.includes = [ den.batteries.define-user den.aspects.shell den.aspects.git ];`:

- user aspects: `shell`, `git`, `lazygit`, `neovim`, `neovim-ide`, `claude`, `ghostty`, `yazi`. `mario` includes the first four (the slim home)
- host aspects, delivered to every user on the host: `dev` (`claude`, `ghostty`, `yazi`, `neovim-ide`, direnv, dev packages; `workstation` includes it), `desktop` (noctalia theme, umbriel, the infra update widget)

Personal-only aspects are opt-in per host: `mario-keys` (SSH authorized keys) and `rex`. NixOS features that persist state guard on the preservation module, so they also evaluate on a persistent root, though paths still assume the user `mario`. Overridable downstream:

- `claude.settings` (home-manager): a JSON-typed option. Keys merge, shared scalars are `mkDefault` so a plain definition overrides them, lists (`permissions.allow`/`deny`, hooks) append (`mkForce` to replace)
- git: `~/.config/git/local` is included at the end of `~/.config/git/config`, so any key there wins over the shared config: `user.email`, `user.signingkey`, `commit.gpgsign = false`, eg `xdg.configFile."git/local".text = "[user]\nemail = ...\n"`. `~/.gitconfig`, if present, is read after both and wins over them
- `system.stateVersion`, `home.stateVersion`, darwin `determinateNix.customSettings.{eval-cores,use-case-hack}`: `mkDefault`

## Usage

Run `just` to list recipes. Common ones:

```sh
just rebuild   # apply config to this machine
just check     # evaluate every host, ISO, and package
just update    # update flake inputs
just iso       # build the installer ISO
just vm        # run the e2e VM
```

## Install

Boot the installer ISO (`just iso`) and run `infra-install [host]`. It partitions with disko, sets up LUKS, installs, and clones this repo to `~/.config/infra`.

> [!NOTE]: Root is ephemeral. Persisted paths live in `modules/features/preservation.nix`.
